# fill it up · 玩法原型

静态网格覆盖解谜原型：在有限预算内放置四向发射器，覆盖全部目标。

- 01 南极冰封：基础覆盖 + 阻挡
- 02 花园洒水：禁覆盖格
- 03 舞台布光：双照格 + 反射格
- 04 博物馆监控：不可放置格 + 发射器不得互照
- 05 车间喷涂：限射程发射器（短喷嘴）+ 禁覆盖格

单文件离线页面，无外部依赖。
